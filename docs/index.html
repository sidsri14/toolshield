toolshield

Static security linter for MCP tool manifests and tool descriptions (tool-poisoning patterns).

View the sample review report Source on GitHub

What it catches

  • Instruction-like text in descriptions (ignore previous instructions, do not tell the user, exfiltration, fetch-and-execute)
  • Invisible zero-width and bidi control characters hiding text from reviewers
  • Credential-harvesting parameter names and unconstrained command/url strings
  • Tool names that impersonate bash, sudo, or other privileged built-ins
  • Read-sounding names paired with side-effecting descriptions

Zero runtime dependencies. Human, JSON, and SARIF output. GitHub Action ready.

The sample report is generated from a synthetic fixture by a real toolshield scan — not invented findings. toolshield inspects tool-manifest JSON only; it does not execute tools or call servers. See the scope and non-claims. For MCP client/server config linting, see the complementary mcpguard.
